# Contributing

Thank you for taking an interest in Trindle crash reports.

## Found a fault?

Tell us what you did, what you expected, what happened instead, and your version and setup. Please do not include crash notes from other programs or anything personal.

You can report it in either place:

- on Buildmorphic, the Trindle community, if you do not use GitHub;
- as an issue on [GitHub](https://github.com/trindle-os/trindle-crash-reports/issues).

## An idea?

Say what you were trying to do and where the add-on got in the way. You do not need to suggest how to fix it.

## Code changes

Code changes are not taken into this repository. That is simply how the project is set up, and a description of the problem helps far more than a patch. You are free to fork it and change it under the licence.

## Security problems

Please report these privately. See [SECURITY.md](SECURITY.md).
